## 银耳浏览器 0.2.0

- 新增应用内检查更新：只读取本仓库 GitHub Releases 的正式版，可手动检查，也可在启动时和每天定期检查（有限频）。
- 发现新版本后可自动下载（默认仅在 Wi-Fi 下），下载完成后通知你；安装前校验 SHA-256、包名、versionCode 和签名证书，安装需在系统对话框中确认。
- 新增 GitHub Actions：常规编译/Lint/单元测试；打 tag 时构建签名 APK 并发布 Release（附 `yiner-update.json` 与 `SHA256SUMS.txt`）。

注意：如果你手机上装的是自己本地构建的调试版，它和这个正式版的签名不同，应用内更新会拒绝安装。需要先卸载旧版（会丢失标签、历史和登录状态），再安装本 Release 中的 APK。之后的版本就可以在应用内更新了。

本版仍不包含任何 AI 功能。
