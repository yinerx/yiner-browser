## 银耳浏览器 0.3.0

- 界面改为 Arc Search Android 风格（标签网格、底部地址栏、搜索页）。
- 内核从 GeckoView 换成基于 Chromium 的系统 WebView（使用手机上的 Android System WebView，不是完整的 Chromium 浏览器）。
- 新增外观设置：跟随系统（新安装默认）、浅色、深色。
- 保留：默认搜索 Google、广告/跟踪屏蔽、无痕隔离、检查更新与安装前安全校验、证书错误不放行。仍不包含任何 AI 功能。

升级须知：可直接覆盖安装 0.2.0，不需要卸载。已打开的标签会按网址重新打开（页内前进/后退记录不保留）。由于内核更换，0.2.0 的 Cookie 与登录状态无法迁移，升级后需要重新登录各网站（包括 Google 账号）。旧内核数据不会自动删除，可在设置中的“清理旧内核数据”手动清理。
